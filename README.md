# Fast Data Services 🇬🇭

Buy non-expiry MTN, Telecel & AT data bundles in Ghana. Pay with MoMo, track orders, and get help from Tay AI.

## Quick start

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add your Supabase and Moolre keys.

## Admin

Sign in at `/login` with your admin account, then open `/admin` for the FDS Nexus operations console.

Demo (if seeded): `admin@fastdataservices.com` / `admin123`
